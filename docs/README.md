# M5 Programación Avanzada en JavaScript  
## Proyecto: TaskFlow 📋☑️

### Introducción  
El proyecto **TaskFlow** consiste en el desarrollo de una aplicación web interactiva para la gestión de tareas, utilizando **JavaScript moderno** y aplicando conceptos de **programación orientada a objetos (POO)**, manipulación del **DOM**, manejo de **eventos**, asincronía y consumo de **APIs**.  

### Objetivos  
- Crear, editar y eliminar tareas.  
- Mejorar la interactividad mediante eventos del DOM.  
- Implementar asincronía para simular procesos y notificaciones.  
- Integrar consumo de APIs y almacenamiento local.  

### Desarrollo  
**POO en JavaScript**  
- Se implementaron las clases `Tarea` y `GestorTareas` para estructurar el código de manera modular y escalable.  

**Características ES6+**  
- Se aplicaron `let`, `const`, template literals, arrow functions, destructuring y spread operator.  

**Eventos y DOM**  
- Se creó un formulario para agregar tareas y se implementaron eventos `submit`, `click`, `mouseover` y `keyup`.  

**Asincronía**  
- Se usaron `setTimeout` y `setInterval` para simular retardos, notificaciones y contadores regresivos.  

**Consumo de APIs**  
- Se integró `fetch()` para obtener tareas desde una API externa y se utilizó `localStorage` para persistencia local.  

### Conclusiones  
- Correcta aplicación de POO.  
- Uso de sintaxis moderna ES6+.  
- Interactividad mediante eventos.  
- Manejo de asincronía.  
- Consumo de APIs y almacenamiento local.  

**TaskFlow demuestra cómo aplicar JavaScript moderno en un caso práctico de gestión de tareas, logrando una aplicación funcional, escalable y fácil de usar.**
